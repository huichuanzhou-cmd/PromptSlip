# Naming history

The project was previously named **PasteDrop**. A bounded GitHub repository-name search on 2026-10-11 returned 15 PasteDrop results, including eight exact-name matches such as [lanxiuyun/PasteDrop](https://github.com/lanxiuyun/PasteDrop), [lobedron/pastedrop](https://github.com/lobedron/pastedrop), and [aalemayhu/pastedrop](https://github.com/aalemayhu/pastedrop). The same search returned zero results for PromptSlip, which was then considered as a candidate. The owner has since finalized **PromptSlip** as the product and public repository name.

These counts describe only that dated, limited repository-name query. They do not establish trademark status, ownership, product availability, or legal clearance. No further naming research is part of this update.
